## 🐛 Reporting Issues

Found a bug? Please help us fix it!

### Before Reporting

1. **Search existing issues** to avoid duplicates
2. **Check if it's already fixed** in the latest version
3. **Verify it's reproducible** on your system
4. **Gather relevant information** (logs, screenshots, versions)

### How to Report

1. Go to the repository's Issues tab
2. Click "New Issue"
3. Choose the appropriate template:
   - **Bug Report**: For reproducible bugs
   - **Feature Request**: For new functionality
   - **Improvement**: For enhancements to existing features
4. Fill out the template completely
5. Submit the issue

[Report a Bug](../../issues/new?template=bug_report.yml)

## 📖 Self-Service Resources

### Troubleshooting Guides

Common issues and solutions:

1. **Installation Problems**
   - Ensure you meet all prerequisites
   - Check for conflicting dependencies
   - Try a clean install

2. **Build Failures**
   - Clear cache and rebuild
   - Update dependencies
   - Check Node/Python/etc. version

3. **Runtime Errors**
   - Check logs for error messages
   - Verify configuration files
   - Ensure environment variables are set

## 🌟 Best Practices for Getting Help

### Be Specific

❌ "It doesn't work"
✅ "When I run `npm start`, I get error XYZ on line 123"

### Provide Context

Include:
- Operating system and version
- Software/package versions
- Full error messages
- Steps to reproduce
- What you've already tried

### Be Respectful

- Follow our [Code of Conduct](CODE_OF_CONDUCT.md)
- Be patient and courteous
- Remember maintainers are often volunteers
- Show appreciation for help received

### Format Code Properly

Use code blocks for code snippets:

```javascript
// Your code here
```

### Search First, Ask Second

Many questions have already been answered:

1. Search closed issues
2. Check discussions
3. Read documentation
4. Google the error message
